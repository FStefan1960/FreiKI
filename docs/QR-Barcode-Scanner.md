Unter den Werkzeugen gibt es einen QR-/Barcode-Scanner. Er liest über die Kamera QR-Codes und Barcodes (EAN, PZN, WLAN, vCard, mailto, Links) und schlägt automatisch passende Aktionen vor: bei Produkt-Barcodes eine Produktsuche inklusive Allergene und Spuren, bei PZN-Codes eine Suche nach dem Beipackzettel, bei Links das Öffnen der Seite, bei WLAN-Codes die Zugangsdaten, bei Visitenkarten das Speichern als Kontakt.

Zusätzlich gibt es ein eigenes Code-Format für interne Dokumente: APPDOC:<Dokument-ID>. Ein solcher Code verweist auf ein bestimmtes Dokument im Paperless-Archiv und lässt sich nur innerhalb der App öffnen, nicht mit einer normalen Handy-Kamera-App - passend für Aufkleber an Geräten, Räumen oder Materialien, die z. B. auf eine Bedienungsanleitung oder Pflegehinweise verweisen sollen, ohne dass der Inhalt öffentlich zugänglich wird.

Erzeugt werden solche Codes im Werkzeug "QR-Code erstellen": dort einfach APPDOC: gefolgt von der gewünschten Dokument-ID eingeben, der QR-Code kann dann ausgedruckt und aufgeklebt werden. Gescannt wird er wie jeder andere Code über den QR-/Barcode-Scanner - erscheint ein "Dokument öffnen"-Button, öffnet ein Klick das hinterlegte Dokument direkt in der App. Der Zugriff ist dabei an die Bereichsrechte des angemeldeten Nutzers gekoppelt: nur wer für den passenden Bereich freigeschaltet ist, kann das Dokument tatsächlich öffnen.
